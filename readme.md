# CrawlerAI
一个基于人工智能的多功能网络爬虫项目，集成多平台数据抓取与AI处理能力，为内容分析、数据挖掘和AI模型训练提供高质量的数据源支撑。

## 项目简介
CrawlerAI 是一套综合性的网络爬虫系统，深度整合了主流社交媒体与内容平台的爬虫能力，并搭载人工智能处理模块。项目不仅能实现多平台数据的自动化抓取，还可对音视频内容进行转写、对文本数据进行深度处理，最终输出结构化、可直接用于AI训练的高质量数据，一站式解决数据采集与预处理的核心需求。

## 主要功能
### 多平台网络爬虫
支持抓取当下主流内容平台的全类型数据，覆盖平台包括：
- 哔哩哔哩（Bilibili）
- 抖音（Douyin）
- 快手（Kuaishou）
- 小红书（Xiaohongshu）
- 微博（Weibo）
- 知乎（Zhihu）
- 百度贴吧（Baidu Tieba）

核心爬虫能力：
- 平台用户登录认证（支持多种登录方式）
- 多类型内容抓取（视频、图片、图文、纯文字等）
- 评论区数据批量抓取
- 结构化数据本地/数据库存储

### AI 智能处理
1. **音视频内容转换**
   - 视频自动提取音频流
   - 基于 Faster Whisper 的音频转文字（高精度语音识别）
   - 转写文本后处理（标点优化、断句修正、冗余内容过滤）

2. **自然语言处理（NLP）**
   - 检索增强生成（RAG）模型快速构建
   - 文本向量化与嵌入（Embedding）生成
   - 语义检索与相似内容匹配

3. **数据清洗与标准化**
   - 爬取数据自动去重、格式统一
   - 非结构化数据转结构化数据集
   - 符合AI训练标准的数据集输出

## 项目结构

├── AI/ # AI 功能核心模块
│ ├── AI_rag/ # RAG 模型构建与应用子模块
│ └── audio_video/ # 音视频转写与处理子模块
├── crawler/ # 爬虫核心实现目录
│ ├── base/ # 爬虫基础类、接口与抽象层
│ ├── media_platform/ # 各平台爬虫具体实现（按平台分目录）
│ ├── store/ # 数据存储模块（本地文件 / 数据库）
│ ├── cache/ # 缓存管理（Redis / 本地缓存）
│ ├── config/ # 配置加载与管理
│ ├── proxy/ # 代理池与 IP 代理管理
│ └── tools/ # 爬虫工具函数（请求、解析、加密等）
├── data/ # 爬虫数据存储目录（已加入.gitignore）
├── browser_data/ # 浏览器缓存 / 登录数据目录（已加入.gitignore）
├── model_*_model/ # AI 模型存储目录（已加入.gitignore）
└── main.py # 项目主程序入口


## 工作流程
1. **数据采集**：配置爬取参数，运行指定平台的爬虫，获取原始内容与评论数据
2. **数据预处理**：对音视频转写文本，对原始数据进行清洗、去重、格式化
3. **模型构建**：利用处理后的结构化数据，快速搭建RAG或其他NLP模型
4. **模型应用**：基于构建的模型实现语义搜索、智能问答、内容推荐等任务

## 安装与配置
### 环境要求
- 编程语言：Python 3.9+
- 辅助环境：Node.js（部分平台反爬处理需用）
- 音视频工具：FFmpeg（需配置系统环境变量）
- 数据库：MySQL（或PostgreSQL/MongoDB，按需选择）
- 缓存服务：Redis（可选，提升爬虫效率）

### 安装步骤
1. **克隆项目到本地**
   ```bash
   git clone <项目仓库地址>
   cd CrawlerAI

2. **安装 Python 依赖**
   ```bash
   pip install -r requirements.txt

3. **配置环境变量**
   在项目根目录创建 .env 文件，填写必要配置项（示例）：
   LANGCHAIN_API_KEY=
   OPENAI_API_KEY=

4. **AI 模型配置**
   音视频转写模块需自行下载 Faster Whisper 模型（推荐 large-v3 版本），并在 audio_video 模块中配置模型路径
   若使用开源嵌入模型，需下载对应模型文件并配置路径；也可使用 API 形式的大模型服务（如 OpenAI / 智谱 AI）

### 使用方法
- python start_all.py
